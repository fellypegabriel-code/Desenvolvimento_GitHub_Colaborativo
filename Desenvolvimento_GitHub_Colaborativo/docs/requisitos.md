# Requisitos do Sistema - TaskFlow

## Requisitos Funcionais (RF)
* [RF01] O sistema deve permitir o cadastro de novas tarefas através de um formulário.
* [RF02] O sistema deve exibir a lista de tarefas todas cadastradas na tela, para que o usuario possa desenvolver.
* [RF03] O sistema deve permitir que o usuário marque a sua tarefa como concluída.
* [RF04] O sistema deverar exibir uma mensagem indicativa quando não houver tarefas cadastradas.

## Requisitos Não Funcionais (RNF)
* [RNF01] A interface deve ser desenvolvida em HTML5, CSS3 e JavaScript puro.
* [RNF02] O sistema deve rodar diretamente no navegador web, sem a necessidade de banco de dados ou servidor.
